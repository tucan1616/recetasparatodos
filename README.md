# Recetario

App de recetas de cocina en un solo archivo HTML, sin dependencias ni paso de compilación.

## Funciones

- Búsqueda por plato o ingrediente
- Categorías: Entrantes, Principales, Ensaladas, Contornos, Postres y Favoritas
- Raciones ajustables
- Formulario para crear recetas propias (se guardan en el navegador)
- Temporizadores automáticos en los pasos con minutos u horas
- Lista de la compra

## Probarla en local

Abre `index.html` en el navegador.

## Desplegar en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel: **Add New → Project** e importa el repositorio.
3. Deja el preset en **Other**, sin comando de build ni directorio de salida.
4. Pulsa **Deploy**. Vercel te dará una URL pública.
